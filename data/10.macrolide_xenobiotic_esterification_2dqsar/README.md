# Macrolide Xenobiotic Esterification 2D-QSAR Results

This directory is the traceable archive for the xenobiotic esterification
design set built from four 16-membered macrolide scaffolds:

- tylosin
- tilmicosin
- tylvalosin
- tildipirosin

## Background

The CSV files in this folder record esterification products formed by
connecting an exogenous metabolite containing one `-COOH` group to one
hydroxyl site on the macrolide scaffold.

The source metabolite pool was filtered to the uniquely esterifiable
mono-carboxylate set used in the xenobiotic esterification workflow. The final
design set contains 196 metabolites.

The resulting product counts are:

- `tildipirosin_esterification_products_2dqsar.csv`: 588 products
- `tilmicosin_esterification_products_2dqsar.csv`: 784 products
- `tylosin_esterification_products_2dqsar.csv`: 980 products
- `tylvalosin_esterification_products_2dqsar.csv`: 588 products

## Data Source

These tables were generated by the xenobiotic esterification script:

- `scripts/esterify_xenobiotics_with_reference_scaffolds.py`

The script uses the four reference scaffolds above and the 196 selected
exogenous metabolites to generate all scaffold-site-metabolite combinations.

## Why This Folder Exists

This folder is meant to preserve the exact source background of the design
results so downstream users can trace:

- which scaffold was used
- which hydroxyl site was selected for esterification
- which metabolite was attached
- whether the product sanitized successfully
- what the canonical product SMILES is
- what `pMIC_pred` was assigned by the 2D-QSAR model

## `pMIC_pred` Meaning

`pMIC_pred（μmol/ml）` is a predicted activity score from Yuan Jie's 2D-QSAR
model. That model was built from MOE molecular descriptors and a set of 104
compounds with MIC data.

Interpretation:

- larger `pMIC_pred` values indicate stronger predicted antibacterial activity
- smaller `pMIC_pred` values indicate weaker predicted antibacterial activity
- use the value as a model ranking score, not as a direct experimental MIC

The column name is kept unchanged to preserve traceability to the source files.

## `raw/` Directory

The `raw/` folder contains the original CSV files from the 2D-QSAR prediction
workflow. Compared to the main directory CSVs, these files include an additional
column `original_pMIC_pred（μmol/ml）` that stores the raw predicted pMIC values
with more decimal places (higher precision) from Yuan Jie's 2D-QSAR model.

Use these files when you need the unrounded prediction values for downstream
analysis.

## File Notes

- The CSVs are stored in an `ISO-8859-1` compatible encoding and are readable
  with `GB18030` in practice.
- The product generation is deterministic for a fixed scaffold, hydroxyl
  site, and metabolite input set.
- This directory is intended as the canonical source-of-truth location for the
  xenobiotic macrolide esterification results.
