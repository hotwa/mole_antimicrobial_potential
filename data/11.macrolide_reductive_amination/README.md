# Macrolide Reductive Amination Products

This directory contains the reductive amination products formed by connecting
exogenous metabolites containing primary amine groups (`-NH2`) to the aldehyde
sites on two 16-membered macrolide scaffolds:

- Tylosin (泰乐菌素)
- Tylvalosin (泰万菌素)

## Background

The reductive amination reaction connects seed metabolites (from the MPMDB
xenobiotic pool) to macrolide scaffolds via their aldehyde functional groups.
This is a different design strategy compared to the esterification approach in
`10.macrolide_xenobiotic_esterification_2dqsar/`.

## Reaction Details

- **Reaction type**: Reductive amination (`[*:1][CX3H1:2]=[OX1].[NX3;H2:4][CX4;!a:5]>>[*:1][CH2:2][NH:4][CX4;!a:5]`)
- **Seed metabolites**: 104 unique xenobiotic metabolites with primary amine groups
- **Amine site distribution**:
  - 92 seeds have exactly 1 strict primary aliphatic amine site
  - 12 seeds have 2 strict primary aliphatic amine sites
- **Theoretical site enumeration**: 92 × 1 + 12 × 2 = 116 reaction sites per scaffold
- **After canonical SMILES deduplication**: 114 unique products per scaffold (2 duplicates removed)

## Files

- `tylosin_seed_amine_products.csv`: 114 unique reductive amination products for Tylosin
- `tylvalosin_seed_amine_products.csv`: 114 unique reductive amination products for Tylvalosin

## Column Descriptions

| Column | Description |
|--------|-------------|
| `product_id` | Unique product identifier (e.g., `tylosin_seed_amine_0001`) |
| `macrolide_name` | Name of the macrolide scaffold |
| `macrolide_input_smiles` | SMILES of the input macrolide |
| `seed_metabolite_id` | MPMDB metabolite ID |
| `seed_metabolite_name` | Name of the seed metabolite |
| `seed_canonical_neutral_smiles` | Canonical neutral SMILES of the seed |
| `seed_n_primary_amine` | Number of primary amine sites on the seed |
| `reaction_smarts` | Reaction SMARTS used for the transformation |
| `aldehyde_match_atoms` | Atom indices of the aldehyde group matched |
| `amine_match_atoms` | Atom indices of the amine group matched |
| `new_cn_bond_product_atoms` | Atom indices forming the new C-N bond |
| `product_smiles` | SMILES of the reaction product |
| `canonical_product_smiles` | Canonical SMILES of the product (used for deduplication) |
| `product_mw` | Molecular weight of the product |
| `product_heavy_atom_count` | Number of heavy atoms in the product |
| `reaction_status` | Status of the reaction (success/failed) |
| `notes` | Additional notes (e.g., multi-amine seed markers) |
| `image_path` | Path to the product structure image |
| `pMIC_pred(μmol/ml)` | Predicted pMIC from the 2D-QSAR model (rounded) |
| `original_pMIC_pred(μmol/ml)` | Original predicted pMIC with full precision |

## Notes on Multi-Amine Seeds

The 12 seeds with 2 primary amine sites are marked with
`multi_primary_amine_seed; enumerated_site` in the `notes` column. These seeds
generate 2 products per scaffold (one for each amine site), resulting in a
total of 116 theoretical products before deduplication.

After canonical SMILES deduplication, 2 products are removed, leaving 114
unique products per scaffold.

## File Encoding

The CSV files use `ISO-8859-1` compatible encoding (readable with `GB18030`).

## Source

Products were generated by the macrolide seed amination script from the
`macro_split` project repository.
