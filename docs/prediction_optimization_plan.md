# 预测管线优化方案

## 当前性能瓶颈分析

基于 8000 分子的基准测试数据：

| 阶段 | 时间 | 速度 | 占比 |
|------|------|------|------|
| MolE 表征 | 10.58s | ~756 mol/s | 26.5% |
| XGBoost 预测 | 20.17s | ~397 mol/s | **50.6%** |
| 分数聚合 | 8.56s | ~935 mol/s | 21.5% |
| 其他 | 0.58s | - | 1.4% |
| **总计** | **39.89s** | **~200 mol/s** | **100%** |

**结论**: XGBoost 预测是最大瓶颈 (50.6%)

**优化方案**:

#### 方案 A: 增加 classifier_workers
```python

# 优化配置

```

**预期效果**:
- 8 workers: ~8x 加速 (理论值)
- 实际效果: 由于 XGBoost 内部已使用多线程，可能只有 2-4x 加速

#### 方案 B: 使用 XGBoost GPU 预测
```python

model = xgb.XGBClassifier(tree_method='gpu_hist', gpu_id=0)
```

**预期效果**: 5-10x 加速

## 8400 亿分子枚举时间预估

### 枚举阶段
- **分子数量**: 840 亿 (8.4 × 10^10)
- **枚举速度**: 1643 mol/s (6 workers)
- **时间**: 8.4 × 10^10 / 1643 ≈ 5.1 × 10^7 秒 ≈ **590 天**

### 预测阶段 (优化后)
- **分子数量**: 840 亿
- **预测速度**: ~800 mol/s (优化后)
- **时间**: 8.4 × 10^10 / 800 ≈ 1.05 × 10^8 秒 ≈ **1215 天**

### 总时间
- **枚举**: 590 天
- **预测**: 1215 天
- **总计**: ~1805 天 (~5 年)

**结论**: 即使优化后，处理 8400 亿分子仍然需要数年时间。

## 建议策略

### 1. 分层筛选
```

    ↓ 实验验证
```

### 2. 早期过滤
- **分子量过滤**: 排除分子量 > 500 的分子
- **Lipinski 规则**: 排除不符合 Lipinski 五规则的分子
- **子结构过滤**: 排除含有毒性子结构的分子
- **多样性筛选**: 使用聚类选择代表性分子

### 3. 分布式计算
- **多节点**: 使用集群进行分布式计算
- **云服务**: 使用 AWS/GCP 的 GPU 实例
- **预计算**: 预计算常见 scaffold 的枚举结果

### 4. 增量更新
- **断点续传**: 已实现，支持中断后继续
- **增量预测**: 只预测新枚举的分子
- **结果缓存**: 缓存已预测的分子结果
